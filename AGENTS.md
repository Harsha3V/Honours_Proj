# Workspace Guidelines — Transparent Pair Programming

## Communication & Explanation Rules
1. **Always Explain Actions Clearly**:
   - Walk through what was inspected, why it was checked, and what was found before and after executing changes.
   - Break down complex hardware architectures, memory maps, and register offsets into clear, educational explanations so the user can easily follow along and learn.
2. **Traceability**:
   - Always link to files and specific line numbers using `[filename](file:///path/to/file#L...)`.
   - Provide concrete comparison tables when validating requirements against specifications (e.g., Excel memory maps).
