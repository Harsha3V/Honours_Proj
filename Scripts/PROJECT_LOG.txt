## ================================================================
## SECTION 1 — WHAT THE PROJECT IS
## ================================================================

This is an Honours Project to build a complete SoC (System-on-Chip)
by integrating:

  1. VeeR EL2 RISC-V Core  — a real 32-bit RISC-V processor (RV32IMC)
  2. AXI Interconnect       — 2-master x 8-slave AXI4 crossbar
  3. AXI4→AXI4-Lite Bridge  — protocol converter
  4. UART                   — serial communication peripheral
  5. IFU ROM Stub           — instruction memory for the CPU

The goal: VeeR EL2 boots from ROM, sets up the UART, and sends
"Hello UART\r\n" over the serial TX pin.

STEP 2 — Created ifu_rom_stub.v  (NEW FILE)
--------------------------------------------------------------
Location: Honours_Proj/rtl/memory/ifu_rom_stub.v

Purpose:
  VeeR IFU needs somewhere to fetch instructions from.
  This module is an AXI4 read-only ROM that:
    - Stores instructions as 32-bit words (ROM_WORDS = 1024 = 4KB)
    - Pairs two 32-bit words into each 64-bit AXI beat (IFU fetches 64-bit)
    - Loads boot.hex at simulation start via $readmemh
    - Supports AXI4 burst reads
    - Accepts write channel transactions silently (IFU never writes)

Key parameter:
  ROM_FILE = "../sw/boot.hex"   (relative to simulation run directory)

--------------------------------------------------------------
STEP 4 — Created boot.S  (NEW FILE — RISC-V Assembly)
--------------------------------------------------------------
Location: Honours_Proj/sw/boot.S

Purpose:
  The program that runs on VeeR EL2 CPU.

What it does:
  1. Sets stack pointer to top of DCCM (0x50020000)
  2. Loads UART base address (0x00000000) into a0
  3. Writes baud divisor = 868 to UART_BAUD_DIV (offset 0x08)
     [100 MHz clock / 115200 baud = 868]
  4. Writes LCR = 0x03 to UART_LCR (offset 0x0C)
     [8-bit word, 1 stop bit, no parity]
  5. Sends "Hello UART\r\n" one byte at a time
     - Polls LSR bit 5 (THRE) before each byte
     - Writes byte to THR (offset 0x00)
  6. Infinite loop (done: j done)

UART Register Map used:
  Offset 0x00 → THR (TX Holding Register) — write TX byte here
  Offset 0x08 → BAUD_DIV — baud rate divisor
  Offset 0x0C → LCR     — line control register
  Offset 0x14 → LSR     — line status register (bit 5 = THRE)

Boot address: 0x80000000 (VeeR reset vector)

STEP 7 — Created tb_veer_uart_soc.v  (NEW TESTBENCH)
--------------------------------------------------------------
Location: Honours_Proj/tb/tb_veer_uart_soc.v

What it does:
  - Generates 100 MHz clock (10 ns period)
  - Holds reset for 20 cycles, then releases
  - Sets rst_vec = 0x80000000 (CPU boots from ROM)
  - Monitors uart_tx_o — detects start bit, samples 8 data bits
  - Prints each received character to console
  - Checks received string against "Hello UART\r\n"
  - Prints PASS or FAIL
  - Timeout = 5 ms simulated time

## SECTION 4 — ERRORS ENCOUNTERED AND FIXED

ERROR 1: RV_ROOT undefined variable
  Cause  : Used bash 'export' syntax in csh shell
  Fix    : Use 'setenv RV_ROOT <path>' in csh

ERROR 2: Undefined macro ASSERT_STATIC_IN_PACKAGE
  File   : el2_mubi_pkg.sv line 41
  Cause  : el2_mubi_pkg.sv was compiled before el2_assert.sv
           which defines the ASSERT_STATIC_IN_PACKAGE macro
  Fix    : Moved el2_assert.sv to TOP of filelist (before all packages)

ERROR 3: Package el2_pkg not defined
  File   : el2_lockstep_pkg.sv line 17
  Cause  : el2_lockstep_pkg imports el2_pkg::* but el2_pkg
           (defined in include/el2_def.sv) was not in filelist
  Fix    : Added $RV_ROOT/design/include/el2_def.sv before
           el2_lockstep_pkg.sv in filelist

ERROR 4: Syntax error in el2_param.vh — token 'pt'
  Cause  : Same root cause as ERROR 3 — el2_param.vh uses
           el2_param_t type which is defined in el2_pkg.
           Once el2_def.sv was added, this resolved automatically.

ERROR 5: Source file axi_to_axilite_uart_bridge.v not found
  Cause  : File is in rtl/bridge/ but filelist had ../rtl/
  Fix    : Updated all Honours Project file paths to correct subdirs:
           ../rtl/bridge/axi_to_axilite_uart_bridge.v
           ../rtl/top/axi_interconnect_uart_top.v
           ../rtl/top/veer_uart_soc_top.v
           ../rtl/memory/ifu_rom_stub.v

ERROR 6: Unconnected interface ports el2_icache_export, el2_mem_export
  File   : el2_veer_wrapper.sv lines 393, 417
  Cause  : el2_veer_wrapper has two mandatory SystemVerilog interface
           ports that must be connected — they cannot be left open.
           These connect the core to DCCM/ICCM/ICache SRAM banks.
  Fix    : Declared 'el2_mem_if mem_export_iface()' in veer_uart_soc_top.v
           and connected:
             .el2_mem_export   (mem_export_iface.veer_sram_src)
             .el2_icache_export(mem_export_iface.veer_icache_src)

ERROR 7: Undefined ports core_rst_l, po_reset_l
  File   : veer_uart_soc_top.v instantiation of el2_veer_wrapper
  Cause  : These ports existed in older VeeR versions but NOT in
           the cloned version (Cores-VeeR-EL2 latest)
  Fix    : Removed those port connections from u_veer instantiation

  Additionally found: This version uses AHB (not AXI) for SB and DMA buses.
  Fix    : Replaced SB/DMA AXI connections with AHB tie-offs.
           Added new ports: lockstep, shadow trace, DMI, ECC outputs,
           performance counters — all tied off or left open.
